# Малюнки Awana

Галерея дитячих малюнків. Діти й малюнки додаються через Telegram-бота, на сайті їх можна лайкати.
Галерея розбита по днях, є рейтинг за день і за весь час.

```
backend/    Node.js: API (Express) + Telegram-бот (Telegraf) + PostgreSQL (Knex)
frontend/   React (Vite)
test-page/  старий тестовий одностраничник
```

## Запуск для розробки

```bash
# 1. База: або своя (вкажи DATABASE_URL), або тестова в Docker на порту 5434
cd backend
docker compose up -d

# 2. Бек + бот
cp .env.example .env     # впиши BOT_TOKEN і DATABASE_URL
npm install
npm run dev              # API на http://localhost:3000, міграції накочуються самі

# 3. Фронт (в іншому терміналі)
cd frontend
npm install
npm run dev              # http://localhost:5173, /api проксіюється на бек
```

Для тестової бази з Docker: `DATABASE_URL=postgres://awana:awana@localhost:5434/awana`.

## Сайт

- **Галерея**: малюнки по днях (за київським часом), сортування «Нові / Популярні»
- **Діти**: список дітей → сторінка дитини з усіма її малюнками по днях
- **Рейтинг**: «За день» — діти й малюнки, намальовані цього дня; «За весь час» — усі

Лайки анонімні: браузер отримує випадковий id у `localStorage`, один лайк на малюнок з браузера.
Повторне натискання знімає лайк.

## API

| Метод | Шлях                        | Опис                                           |
|-------|-----------------------------|------------------------------------------------|
| GET   | `/api/days`                 | дні з малюнками                                |
| GET   | `/api/children`             | діти з кількістю малюнків і лайків             |
| GET   | `/api/drawings?day=&child=` | малюнки за день та/або дитиною                 |
| GET   | `/api/rating?day=`          | рейтинг дітей і топ-10 малюнків (без day — весь час) |
| PUT   | `/api/drawings/:id/like`    | `{ "liked": true/false }`, заголовок `X-Visitor-Id` |

## Продакшн (одна машина, напр. Raspberry Pi)

```bash
cd frontend && npm ci && npm run build
cd ../backend && npm ci --omit=dev
# у .env: STATIC_DIR=../frontend/dist — тоді бек віддає і сайт, і API на одному порту
npm start
```

Попереду можна поставити Caddy для https:

```
awana.turuta.pp.ua {
	encode zstd gzip
	reverse_proxy localhost:3000
}
```

Якщо фронт живе окремо (наприклад, на Netlify): збери його з `VITE_API_URL=https://адреса-бека`,
а в `.env` бека вкажи `CORS_ORIGIN=https://адреса-фронта`.

## Налаштування бека (.env)

| Змінна         | Опис                                                      |
|----------------|-----------------------------------------------------------|
| `BOT_TOKEN`    | токен від @BotFather                                      |
| `DATABASE_URL` | рядок підключення до PostgreSQL                           |
| `PORT`         | порт API (3000)                                           |
| `PUBLIC_URL`   | адреса сайту — бот показує кнопку «🌐 Відкрити сайт»       |
| `STATIC_DIR`   | папка зі зібраним фронтом (необов'язково)                 |
| `CORS_ORIGIN`  | домен фронта, якщо він окремо від бека (необов'язково)    |

Файли малюнків лежать у `backend/uploads/`, прев'ю генеруються в `backend/thumbs/`.
